==========================================
  COMANDO PARA CRIAR O USUÁRIO MYSQL
==========================================

Copie e cole ESTE comando completo no terminal:

sudo mysql -e "CREATE USER IF NOT EXISTS 'stockone_user'@'localhost' IDENTIFIED BY 'stockone_pass_2024'; GRANT ALL PRIVILEGES ON laravel.* TO 'stockone_user'@'localhost'; FLUSH PRIVILEGES; SELECT 'Usuário criado com sucesso!' AS Status;"

==========================================

OU execute passo a passo:

1. sudo mysql

2. Cole estes comandos (um por vez ou todos juntos):
   CREATE USER IF NOT EXISTS 'stockone_user'@'localhost' IDENTIFIED BY 'stockone_pass_2024';
   GRANT ALL PRIVILEGES ON laravel.* TO 'stockone_user'@'localhost';
   FLUSH PRIVILEGES;
   EXIT;

3. Depois execute:
   php artisan config:clear
