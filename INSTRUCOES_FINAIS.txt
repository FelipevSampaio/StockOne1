⚠️  O menu público está com erro porque o usuário MySQL não existe.

✅ SOLUÇÃO (EXECUTE NO TERMINAL):

   sudo mysql -e "CREATE USER IF NOT EXISTS 'stockone_user'@'localhost' 
   IDENTIFIED BY 'stockone_pass_2024'; GRANT ALL PRIVILEGES ON laravel.* 
   TO 'stockone_user'@'localhost'; FLUSH PRIVILEGES;"

📝 OU EXECUTE PASSO A PASSO:

   1. Abra o terminal
   2. Execute: sudo mysql
   3. Cole estes comandos:
      
      CREATE USER IF NOT EXISTS 'stockone_user'@'localhost' 
      IDENTIFIED BY 'stockone_pass_2024';
      
      GRANT ALL PRIVILEGES ON laravel.* TO 'stockone_user'@'localhost';
      
      FLUSH PRIVILEGES;
      
      EXIT;

🧪 DEPOIS DE EXECUTAR:

   php artisan config:clear
